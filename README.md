# F1 STATS

Русскоязычный анализ гоночного темпа по данным [OpenF1](https://openf1.org). Статический сайт без сборки, сервера и API-ключа для исторических сессий с 2023 года.

## Возможности

- Выбор завершённой гонки или спринта.
- Покруговая таблица с составом шин, возрастом и номером отрезка.
- Автоматическое исключение первого круга, PIT, OUT, SC/VSC и красных флагов.
- Включение / исключение любого круга с корректным временем; массовый выбор диапазона для отображаемых пилотов и отрезка.
- Средние по отрезкам и гонке, разница с быстрейшим средним темпом.
- Сохранение выбора в localStorage, экспорт и импорт JSON с проверкой сессии.

## Запуск

Открыть каталог через любой локальный HTTP-сервер, например `npx --yes http-server .`. Открытие index.html через file:// не подходит для ES-модулей.

Проверки: `npm test` (Node.js 20+).

## GitHub Pages

В Settings → Pages выбрать Deploy from a branch → main → /(root). Файл `.nojekyll` отключает обработку Jekyll. Для приватных репозиториев доступность Pages зависит от тарифа GitHub; видимость репозитория эта инструкция не меняет.

## Методика и ограничения

Среднее гонки считается по всем включённым кругам, а не по средним отрезков. Фильтр отрезка меняет покруговую таблицу, но не итог гонки. Сравнение разных пилотов не нормализуется по топливу, погоде, составу шин или возрасту комплекта.

SC/VSC/RED размечаются по временным интервалам сообщений race_control и пересечению с кругом пилота. Предупреждение IN THIS LAP / ENDING не завершает интервал. Если время начала круга отсутствует, используется номер круга сообщения. Источник может быть неполным: автоматический отбор нужно проверять. Локальные жёлтые флаги, борьба, трафик, ошибки и повреждения автоматически не исключаются. Возраст шин на круге указан к его началу.

Данные загружаются последовательно с ограничением частоты, повтором при HTTP 429 и тайм-аутами. При недоступности API отображается ошибка, вымышленные результаты не подставляются. Живые сессии скрыты; приложение не выполняет авторизованные запросы к live API.

Ручные изменения хранятся только на текущем устройстве в данном браузере и origin. Исходная пользовательская таблица в репозиторий не включена. Независимый проект, не связан с Formula 1 или FIA.
