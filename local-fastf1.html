FastF1 на компьютере

Гонка скачивается через твой аккаунт F1 TV на твоём компьютере. На сайт импортируется только JSON с данными.

  1. Установи Python 3.12 или новее, если его ещё нет.

  2. Скачай архив F1 STATS и полностью распакуй его.

  3. Открой папку f1stats-main и запусти START_FASTF1.cmd. При первом запуске установятся библиотеки.

  4. Введи почту и пароль F1 TV. При вводе пароля символы не отображаются — это нормально. Затем укажи сезон, номер этапа и R для гонки / S для спринта. Для Остина: 2026 → 18 → R.

  5. После успешной загрузки откроется папка exports. Нужен файл 2026-18-R.json, а не index-2026.json.

  6. Вернись на сайт, нажми Импорт FastF1 JSON и выбери этот файл. Сайт сам переключится на FastF1 и откроет гонку.

Импортированная гонка хранится в этом браузере. Исходный JSON оставь у себя: он нужен при смене браузера или очистке его данных. Ручной выбор кругов у FastF1 и OpenF1 сохраняется отдельно.

Если локальная загрузка тоже вернёт HTTP 403, файл не появится. Не перезапускай загрузку много раз — сохрани текст ошибки для проверки.
